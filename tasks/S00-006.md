# S00-006 初期世界生成

## 目的

設定・名前データ・seedから04ミニ仕様の初期世界を決定的に生成する。

## 参照資料

- `AGENTS.md`
- `docs/TECHNICAL_DECISIONS.md`
- `docs/specs/00-domain-glossary.md`
- `docs/specs/02-config-schema.md`
- `docs/specs/03-event-envelope.md`
- `docs/specs/04-initial-world-generation.md`
- `docs/specs/06-name-data.md`
- `docs/specs/07-seeded-rng.md`

## 前提

S00-002、S00-003、S00-005完了。

## 実装範囲

- 決定的IDとsimulationId
- 家系、流派、存命人物、死亡済み祖先
- 親子、婚姻、師弟関係
- 基礎能力・適性・遺伝値
- 家名・個人名・流派名
- 初期イベント、初期スナップショット、検証サマリー

## 変更可能範囲

- `packages/simulation-core/**`
- このタスクで追加するテストfixture・テストファイル

## 対象外

- 週次成長
- 新規出生・死亡
- 大会・戦闘
- MySQL、CLI、ファイルI/O

## 入力

- 検証済み設定、`configHash`、seed、検証済み名前データ、`nameDataHash`、RNG factory、SHA-256 provider。

## 出力

- 04ミニ仕様の初期世界スナップショット、初期イベント、検証サマリー。

## 受入条件

- 存命600人、死亡済み祖先200人、100家、24流派、師匠資格者45人を基準設定どおり生成する。
- 全100家が存続状態で、各家に存命人物が1人以上いる。
- 同一条件でID・名前・能力・関係・イベントまで一致する。
- 壊れた参照、自己参照、親子・師弟循環が0。
- 04・06ミニ仕様の受入条件を満たす。
- `npm run check`が成功する。

## 必須テスト

- 04・06ミニ仕様の全受入テスト
- 基準設定の件数と同一seed完全一致
- 異なるseedで少なくとも一部が変化すること

## 必須コマンド

```text
npm run check
```

## 完了報告

`AGENTS.md`の完了報告形式を使用する。仕様との差異・未解決事項がない場合も「なし」と明記する。
