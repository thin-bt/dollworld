# S00-004 世界暦・一斉加齢

## 目的

01ミニ仕様に基づく世界日時、週送り、年初一斉加齢、年齢資格、42歳強制引退を実装する。

## 参照資料

- `AGENTS.md`
- `docs/TECHNICAL_DECISIONS.md`
- `docs/specs/00-domain-glossary.md`
- `docs/specs/01-world-calendar.md`

## 前提

S00-002完了。

## 実装範囲

- `WorldDate`と世界週の変換
- 01ミニ仕様の「現週終了→日時進行→年初処理」境界
- 年次統計確定通知
- `birthYear`からの年齢再計算
- 4月第1週の一斉加齢と年齢資格更新
- 42歳強制引退時の`currentRank`→`retirementRank`移行と`highestRank`保持

## 変更可能範囲

- `packages/simulation-core/**`
- このタスクで追加するテストファイル

## 対象外

- 出生、結婚、出産、大会、自律引退
- 構造化イベントの永続形式
- CLI、MySQL

## 入力

- 世界日時、人物状態、進行週数。

## 出力

- 更新後の日時・人物状態と、年次統計確定／年初処理を示す決定的結果。

## 受入条件

- 初期世界1年4月第1週で余分な加齢を行わない。
- 初回の一斉加齢は世界2年4月第1週。
- 100年は4,800週進行し、世界101年4月第1週の年初処理後となる。
- 人物ごとの誕生日・誕生週フィールドを作らない。
- `npm run check`が成功する。

## 必須テスト

- 01ミニ仕様「受入テスト」12項目を実装する。

## 必須コマンド

```text
npm run check
```

## 完了報告

`AGENTS.md`の完了報告形式を使用する。仕様との差異・未解決事項がない場合も「なし」と明記する。
