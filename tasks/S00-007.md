# S00-007 世界進行エンジン骨格

## 目的

初期世界を週単位で進める、決定的なProcessorパイプラインを実装する。

## 参照資料

- `AGENTS.md`
- `docs/TECHNICAL_DECISIONS.md`
- `docs/specs/00-domain-glossary.md`
- `docs/specs/01-world-calendar.md`
- `docs/specs/03-event-envelope.md`
- `docs/specs/04-initial-world-generation.md`
- `docs/specs/07-seeded-rng.md`

## 前提

S00-004〜S00-006完了。

## 実装範囲

- Processor interfaceと固定順実行
- 01ミニ仕様の現週終了→日時進行→年初処理
- 年初一斉加齢processor
- イベント集約
- RNGサブストリーム状態の保持
- N週・N年の決定的実行
- 年次統計確定通知の集約

## 変更可能範囲

- `packages/simulation-core/**`
- このタスクで追加するテストファイル

## 対象外

- 修行・戦闘・大会・結婚・出産・死亡processor
- ファイルI/O、CLI、MySQL

## 入力

- 初期世界スナップショット、Processor列、週数または年数、RNG状態。

## 出力

- 最終世界状態、イベント列、年次統計確定通知、更新済みRNG状態。

## 受入条件

- 100年を正確に4,800週進める。
- 年次統計確定通知が世界年1〜100の100回。
- 世界101年4月第1週の年初処理後で終了する。
- 42歳強制引退が反映される。
- 同一入力・同一processor順で完全一致する。
- `npm run check`が成功する。

## 必須テスト

- 空processor列と複数processorの固定順
- 4,800週・100年境界
- RNG状態保存・継続実行
- 同一入力再現性

## 必須コマンド

```text
npm run check
```

## 完了報告

`AGENTS.md`の完了報告形式を使用する。仕様との差異・未解決事項がない場合も「なし」と明記する。
