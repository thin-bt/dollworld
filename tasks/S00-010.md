# S00-010 再現性・不変条件・性能試験

## 目的

Sprint 0全体の固定完了条件を自動検証する。

## 参照資料

- `AGENTS.md`
- `docs/TECHNICAL_DECISIONS.md`
- `docs/specs/00-domain-glossary.md`
- `docs/specs/01-world-calendar.md`

- `docs/specs/05-statistics-output.md`
- `docs/specs/06-name-data.md`
- `docs/specs/07-seeded-rng.md`
- `docs/SPRINT_0_BACKLOG.md`

## 前提

S00-009完了。

## 実装範囲

- 同一seed・同一設定の決定的比較
- 異なるseedでの差分確認
- 全不変条件の統合検証
- 10／50／100／300年ベンチ
- 600／2,000／5,000人の性能プロファイル
- Sprint 0完了レポート

## 変更可能範囲

- `packages/simulation-core/**`と`apps/simulator/**`のテスト・検証コード
- 性能・統合テスト用fixture
- ルート`package.json`の検証スクリプトを必要最小限で更新

## 対象外

- ゲームバランスの自動調整
- MySQL、Web UI
- 性能目標超過を理由にした仕様変更

## 入力

- 基準設定と拡大用テスト設定、固定seed群。

## 出力

- 再現性比較、validation report、performance report、Sprint 0完了判定。

## 受入条件

- 壊れた参照・不変条件違反0。
- 同一条件の決定的出力が一致する。
- 100年は4,800週、年次統計100行、固定7ファイル。
- 600人・100年と2,000人・100年の警告基準を計測し、超過は警告として記録する。
- 5,000人は計測のみ。
- `npm run check`が成功する。

## 必須テスト

- 同seed比較、異seed差
- 全ID・参照・年齢・参加状態・ランク不変条件
- 10／50／100／300年
- 600／2,000／5,000人性能計測

## 必須コマンド

```text
npm run check
npm run simulate -- --years 100 --seed 12345 --config config/initial-world.config.json
```

## 完了報告

`AGENTS.md`の完了報告形式を使用する。仕様との差異・未解決事項がない場合も「なし」と明記する。
