# S00-009 固定7ファイル出力

## 目的

05ミニ仕様どおり`output/<run-id>/`へ固定7ファイルを安全に出力する。

## 参照資料

- `AGENTS.md`
- `docs/TECHNICAL_DECISIONS.md`
- `docs/specs/03-event-envelope.md`
- `docs/specs/05-statistics-output.md`

## 前提

S00-008完了。

## 実装範囲

- run metadata
- initial／final world JSON
- yearly statistics CSV
- events JSONL
- validation report
- performance JSON
- runId生成
- 一時ディレクトリを使うatomic writeと失敗時cleanup

## 変更可能範囲

- `apps/simulator/**`
- ルートスクリプトの必要最小限の更新
- このタスクで追加するテストファイル

## 対象外

- DB保存
- グラフ、UI
- 詳細戦闘ログの保持期間処理

## 入力

- 実行メタデータ、初期／最終状態、年次統計、イベント、検証結果、性能計測。

## 出力

- 05ミニ仕様で固定した7ファイル。

## 受入条件

- 100年実行でCSVが世界年1〜100の100行。
- 7ファイルを再読込できる。
- 決定的データ部分は同一seedで一致する。
- 途中失敗で不完全な最終runディレクトリを残さない。
- `npm run check`が成功する。

## 必須テスト

- 05ミニ仕様の全受入テスト
- JSON・CSV・JSONL再読込
- runId形式
- atomic write成功・失敗

## 必須コマンド

```text
npm run check
npm run simulate -- --years 100 --seed 12345 --config config/initial-world.config.json
```

## 完了報告

`AGENTS.md`の完了報告形式を使用する。仕様との差異・未解決事項がない場合も「なし」と明記する。
