# S00-008 ヘッドレスCLI

## 目的

`apps/simulator`から年数、seed、設定を指定してシミュレーションを実行できるCLIを作る。

## 参照資料

- `AGENTS.md`
- `docs/TECHNICAL_DECISIONS.md`
- `docs/specs/02-config-schema.md`
- `docs/specs/04-initial-world-generation.md`
- `docs/specs/05-statistics-output.md`
- `docs/specs/06-name-data.md`

## 前提

S00-007完了。

## 実装範囲

- `apps/simulator` npm workspace
- Node標準`node:util`の`parseArgs`
- 設定・manifest・名前候補JSONのファイル読込
- `node:crypto`を使う`Sha256Provider`具象実装
- シミュレーション実行の組立て
- 終了コードと簡潔な標準出力
- ルート`simulate`スクリプト

## 変更可能範囲

- `apps/simulator/**`
- ルート`package.json`と`package-lock.json`の必要最小限の更新
- このタスクで追加するテストファイル

## 対象外

- 固定7ファイルの本書出し（S00-009）
- Web、MySQL
- ゲーム本体processor
- 外部CLIライブラリ

## 入力

- `--years`、`--seed`、`--config`と名前manifest。

## 出力

- 成功／失敗の終了コード、実行サマリー。S00-008では7ファイル出力を完了条件にしない。

## 受入条件

- help、正常実行、不正引数、不正設定の終了コードが定義どおり。
- `--years 100 --seed 12345 --config config/initial-world.config.json`を実行できる。
- `simulation-core`が`node:crypto`を直接importしない。
- 外部実行時依存を追加しない。
- `npm run check`が成功する。

## 必須テスト

- help表示
- 正常引数
- 不足・不正引数
- 不正設定・不正名前データ
- SHA adapterの既知値

## 必須コマンド

```text
npm run check
npm run simulate -- --years 1 --seed 12345 --config config/initial-world.config.json
```

## 完了報告

`AGENTS.md`の完了報告形式を使用する。仕様との差異・未解決事項がない場合も「なし」と明記する。
