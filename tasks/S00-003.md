# S00-003 Seeded RNG

## 目的

同じseedから同じ乱数列・選択・シャッフルを返す、07ミニ仕様準拠のRNGを実装する。

## 参照資料

- `AGENTS.md`
- `docs/TECHNICAL_DECISIONS.md`
- `docs/specs/07-seeded-rng.md`

## 前提

S00-001完了。S00-002と並行実装可能。

## 実装範囲

- `xoshiro128ss-v1`の状態初期化と`nextUint32`
- `nextFloat`、`nextInt`、`chance`、`choose`、非破壊`shuffle`、重複なし`sampleWithoutReplacement`
- `deriveSeed`
- 状態export／importとalgorithmVersion

## 変更可能範囲

- `packages/simulation-core/**`
- このタスクで追加するテストファイル

## 対象外

- 人物・家系・ID生成
- 初期世界生成
- 暗号用途
- `Math.random()`、現実時刻、OS・crypto乱数

## 入力

- 0〜4294967295の整数seed、安定したASCII label、配列入力。

## 出力

- 07ミニ仕様のRNG APIと直列化可能な状態。

## 受入条件

- seed 12345の初期状態・先頭10値・派生seedがgolden値と一致する。
- 範囲外seed・不正引数を拒否する。
- 入力配列を変更しない。
- 状態復元後の列が一致する。
- `Math.random`を使用しない。
- `npm run check`が成功する。

## 必須テスト

- 07ミニ仕様「受入テスト」13項目を実装する。

## 必須コマンド

```text
npm run check
```

## 完了報告

`AGENTS.md`の完了報告形式を使用する。仕様との差異・未解決事項がない場合も「なし」と明記する。
