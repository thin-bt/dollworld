# S00-007 世界進行エンジン骨格

## 概要

初期世界を週単位で進める決定的 Processor パイプラインを実装する。

## 現在確定している内容

### 確定した実装範囲

- Processor interface と固定順実行
- 現週終了→日時進行→年初処理、一斉加齢
- イベント集約、RNG サブストリーム状態保持
- N週・N年実行と年次統計確定通知

### 主な変更領域

- `packages/simulation-core/src/world-engine/`

### 重要な受入条件

- 100年=4800週
- 年次統計確定通知100回（世界年1〜100）
- 世界101年4月第1週年初後終了
- 42歳強制引退
- 同一入力・同一 processor 順で完全一致
- `npm run check`

### 関連commit

- `7bf868e51027865fe73779ad2b21c7b83514b7af` — 実装および最終受入監査残件修正（master 履歴上、当該タスクの確認できる commit）
