# S01-004 週間行動・訓練・技習得

## 概要

週間Plannerと訓練／習得／練習／休養。大会・戦闘は対象外。

本ページは説明・索引である。正本は [docs/SPRINT_1_BACKLOG.md](../../SPRINT_1_BACKLOG.md)。

Sprint 1全体は未完了。次タスクはS01-006。WorldEngine接続はS01-008。

## 現在確定している内容

- 依存: S01-002、S01-003（implemented）
- 仕様版: `S1-SPEC-0.1.20`（週間processor literal／sidecar契約は0.1.20で固定。純粋関数本体はS01-004実装済み）
- 実装状態: **implemented**（WorldEngine登録・sidecar runtime ownerはS01-008）
- production `processorId`／`sourceProcessor` literalは `weekly-training`（S1-SPEC-0.1.20）
- `InitialWeeklyTrainingSidecarSnapshot` schemaVersion `0.1.0`。Person外required欠落のdefault禁止
- 週間行動列挙は `train_stat | learn_technique | practice_technique | rest | inactive`
- 強制休養理由は `severe_injury`／`fatigue_threshold` の2種のみ
- rest fallback理由は `no_trainable_stat`／`no_learning_candidate`／`no_practice_candidate`
- 行動scoreと目標scoreは整数 `scoreHundredths`。小数・`Math.round` を使わない
- 係数積は `multiplyBasisPointsFloor`（BigInt厳密積・`10000^n` で一括floor）
- 効果RNGは `drawInclusiveBasisPoints`（`nextInt(minBp, maxBp + 1)`）
- `TrainingProcessorRuntimeState` schemaVersion `0.1.0`。`processedPersonCount` は4行動カウント合計と一致
- 週開始スナップショットを凍結し、師匠参照・弟子参照は同週内の更新結果を見ない
- 途中失敗時は部分結果を返さず、入力・RNG状態を変更しない
- 同一週再処理と週番号逆行を拒否する
- イベントはcandidateのみ。`eventId`／`simulationId`／`sequence` を持たない
- inactiveを含む全人物に`Sprint1PersonState`必須。欠落・catalog意味不正は週全体failure
- 週開始時の`normalizeWeeklyLearningFocus`でfocusを維持／解除（行動種別に依存しない）
- effect後の`validateProcessedWeeklyPersonRecord`で再検証し、1人失敗でも週全体rollback
- `Person`はliving／deceased unionの構造契約を検証してから返す（部分field＋cast禁止）
- `rngState`は`validateSeededRngState`でhardenしてからimport
- 正式訓練対象は年齢8..41（`isFormalTrainingEligible`）。42歳以上はrest限定（RNG 0、fallbackなし）
- teacher contextの`masterCareerStatus`は正式CareerStatus列挙のみ（S01-003 `teacherCanTeach`と共用）
- package rootから内部draft／effect／`validateProcessedWeeklyPersonRecord`を除外
- `technique.learning_progressed.unit = "tenths"`／`technique.mastery_increased.unit = "hundredths"`。acquiredは既存payload維持
- WorldEngine登録は行わない（S01-008）

### 正本にない入力はsidecarとして受け取る

正本10・14がゲームルールを定義していない入力（planner context score、関連適性値、師匠推薦度、styleMatch、teacherPriority、学習特性、指導力、相性、`teacherFactorKey`、弟子数）は、本Processorが独自ルールで導出せず、adapter入力として受け取る。既定値は正本が明記するもの（styleMatch欠落→50、teacherPriority欠落→0）だけを適用する。
