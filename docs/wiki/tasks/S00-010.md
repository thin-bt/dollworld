# S00-010 再現性・不変条件・性能試験

## 概要

Sprint 0 固定完了条件を自動検証する。`npm run verify:sprint0` と完了レポートを提供する。

## 現在確定している内容

### 目的

同条件再現性、異 seed 実体差、boundary seed、不変条件、固定7ファイル、年数別検証、人口別性能、完了レポート。

### 確定した実装範囲（要約）

- **同seed再現性**: years100a／years100b を比較。両 run を独立に不変条件・validation・termination・固定7ファイル検証
- **異seed実体差**: simulationId／eventId を除外した実体内容で差を判定（識別メタデータのみの差は合格にしない）
- **boundary seed**: `0` と `4294967295` の各2回。決定性＋各 run の独立検証。長期性能は notPerformed
- **不変条件**: `verifyRunInvariants` 等で統合検証
- **固定7ファイル**: 全ディレクトリエントリ厳密検査
- **10／50／100／300年**: 機能検証。yearProfile の maxRSS は単独測定せず `null`（`not_measured_per_run`）
- **600／2000／5000人**: 独立子プロセスで性能計測。600／2000は警告計測、5000は measure only
- **性能超過は warning**: overallPassed を落とさない
- **`verify:sprint0`**: ルートスクリプトから検証 CLI を実行
- **`sprint0-complete`**: commit `504fa3cc16346dd0c6480e8328e42518e68215d3` に付与
- **2000人100年の性能課題**: 最終測定 171.81s（基準120s）超過 → warning
- **年数別 maxRSS**: 単独測定していない

測定値の詳細は [../decisions/performance-warnings.md](../decisions/performance-warnings.md)。
