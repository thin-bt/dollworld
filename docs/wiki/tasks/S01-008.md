# S01-008 WorldEngine・CLI・出力統合

## 概要

WorldEngine／CLI統合・固定7維持・Sprint 0互換。既存simulationIdは再計算置換しない。

本ページは説明・索引である。正本は [docs/SPRINT_1_BACKLOG.md](../../SPRINT_1_BACKLOG.md)。**production実装済み（implemented / accepted）。** 統合契約は `S1-SPEC-0.1.20` で固定済み。Sprint 1全体は未完了（S01-009は implemented / 受入監査中）。

## 現在確定している内容

- 依存: S01-004、S01-007
- 仕様版: `S1-SPEC-0.1.20`
- 実装状態: **implemented / accepted**。WorldEngine・CLI・fixed7 Sprint1 writersのproduction配線は実装済み。受入監査修正（session／structural／reload／legacyProcessors／promotion equal-id）反映済み
- 確定済み依存順序（履歴）: `S01-008 integration clarifier accepted → S01-008 production implementation / acceptance → S01-009`
- commit対象は`runBattleToCompletion`の`completed`／`resolution_error` planのみ。`pre_start_failure`と`BattleExecutionAbortError`はcommitなし（World RNG／events／participant source不変）

### 再発明してはならない確定契約（S1-SPEC-0.1.20）

- adapter ID／週間event `sourceProcessor` = `weekly-training`（`WEEKLY_TRAINING_PROCESSOR_ID`）
- production adapter pipeline = `[weekly-training]`のみ（legacy `WorldProcessor`／`RunWorldOneWeekInput.processors`へは登録しない。二重実行禁止）。`runSprint1WeeklyStep` の `legacyProcessors` は年末集計などのWorldEngine補助hook専用であり、`weekly-training` を含むSprint1 adapter IDは拒否する
- battleはadapter pipeline外（明示的run／`commitRunBattlePlan`）
- `worldRngState` owner／initial derivation = `deriveSeed(runSeed, "battle/world-rng")` → `createSeededRng(...).exportState()`
- `matchIdGeneratorState` owner = `Sprint1RunRuntimeState`
- `processorRuntimeStates` owner = `Sprint1RunRuntimeState`（既存`ProcessorRuntimeState` collection）
- weekly-training RNG initial derivation = `deriveSeed(runSeed, "processor/weekly-training")`
- `TrainingProcessorRuntimeState` physical location = `processorRuntimeStates.processorSpecificStates` の weekly-training entry（直下重複禁止）。初期値は`createInitialTrainingProcessorRuntimeState()`。`specificState` plain JSON deep-clone
- immutable `Sprint1RunContext`最終shape: `sprint1Config`／`techniqueCatalog`／`initialWeeklyTrainingSidecarSnapshot`／`simulationIdentity`(+hash)／`simulationId`／`runRuleSnapshot`(+hash)。外部`initialMatchIdGeneratorState`依存なし
- 論理`Sprint1RunSession`。`WeeklyTrainingSidecarState`。`battleResultWeekState.absoluteWeek === worldDate.absoluteWeek`。`battleResults`／week suffix invariant
- `PersonTemporaryCondition` current正本 = weekly sidecar。Personへfatigue等新field追加なし。condition／confidenceは`*After`適用
- `battleResults` owner = `Sprint1RunRuntimeState`（run全体canonical store。final-worldへ投影）
- `battleResultWeekState` owner = `Sprint1RunRuntimeState`（同週count専用）
- BattleResult registration: completed＋resolution_errorを両storeへ同一transactionでcommit順append。pre_start_failure／abort／commit failureはappendなし
- completed-only per-person match count（week registryのみ。`battleResults.length`ではない）
- resolution_error registered but count+0
- new absoluteWeekでweek registry reset（`battleResults`は保持。同じouter week transaction）
- double apply duplicate matchId reject（全runtime変更0）
- `eventStream`／global `eventAllocationState` allocator
- weekly sidecar current owner = `Sprint1RunRuntimeState.weeklyTrainingSidecars`；initial owner = `Sprint1RunContext.initialWeeklyTrainingSidecarSnapshot`
- all components same transaction rollback
- **fresh Sprint 1 initialization promotion**（保存済みSprint 0 migrationではない）
- missing sidecar default禁止／CLI `--sprint1-input`のみ／SimulationIdentity `0.4.0`
- `Sprint1RunRuntimeState`オブジェクト自体はcheckpoint非永続。document schema: run-metadata `0.4.0`／initial-world `0.4.0`（`initialWeeklyTrainingSidecarSnapshot`投影）／final-world `0.3.0`（`weeklyTrainingSidecars`＋`battleResults`投影。0.4.0非bump）。fixed7 exactly 7 files（`battle-results.json`禁止）。events.jsonlへturn詳細非複製。Sprint1 retention削除未実装
- S01-007はimplemented / accepted（commit `a39e476`）
- 将来DB-011 binding literalは`WEEKLY_TRAINING_PROCESSOR_ID="weekly-training"`

- 受入条件・対象外・RNG／hash／固定7への影響は正本バックログの本タスク節を正とする
- 正本にない実装方法・未存在クラス名／ファイルパスを本Wikiで追加しない

### production実装済みの主要入口

| 入口 | 役割 |
|---|---|
| `createSprint1RunSession` | fresh Sprint 1 run session 21-step initialization promotion |
| `runSprint1WeeklyStep` | outer weekly transaction（weekly-training adapter → legacy WorldEngine week → commit） |
| `runSprint1Years` | `years * 48` 週を validated-session trust boundary で進める（開始／終了 full validation、各週は transition-local validation。public `runSprint1WeeklyStep` 契約は維持） |
| `commitRunBattlePlan` | battle pipeline外の原子的 RunBattleCommitPlan apply |
| `runSprint1WeeklyTrainingAdapter` | legacy WorldProcessor 非登録の transactional adapter |
| CLI `--sprint1-input` | Sprint 1 new-run モード切替（省略時 Sprint 0 互換） |
| `buildAndWriteSprint1RunOutput` | fixed7 Sprint1 writers（run-metadata 0.4.0／initial-world 0.4.0／final-world 0.3.0） |
