# S00-006 初期世界生成

## 概要

設定・名前・seed から初期世界を決定的に生成する。

## 現在確定している内容

### 確定した実装範囲

- ミニ仕様 04／06 に基づく生成
- 家系・流派・人物・関係・初期イベント

### 主な変更領域

- `packages/simulation-core/src/initial-world/`

### 重要な受入条件

- 存命600・祖先200・100家・24流派・師匠資格45（設定／仕様の数値。config は暫定値）
- 全100家存続・各家存命≥1
- 同一条件完全一致、壊参照・自己参照・循環0
- `npm run check`
