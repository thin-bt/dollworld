# S01-005 戦闘開始・BattleState生成

## 概要

戦闘入力・validation・MatchId・戦闘RNG・snapshot・BattleState。ターン解決は対象外。

本ページは説明・索引である。正本は [docs/SPRINT_1_BACKLOG.md](../../SPRINT_1_BACKLOG.md)。

S01-006／S01-007／S01-008はimplemented / accepted（S01-007 commit `a39e476`）。S01-001〜S01-009はすべて accepted（S01-009受入完了commit `5616f5f`）。残作業は clean master `npm run verify:sprint1` と `sprint1-complete` tag 作成。

## 現在確定している内容

- 依存: S01-001、S01-002、S01-003、S01-004（すべてimplemented）
- 仕様版: `S1-SPEC-0.1.20`
- 実装状態: **implemented / accepted**
- MatchIdは`match-id-generator-0.1.0`のproduction実装。形式 `^match_[0-9]{12}$`、state 5キー固定、枯渇sentinel `1000000000000`
- MatchId操作でRNGを消費しない。seedはstate hashにだけ効き、MatchId文字列へ混ざらない
- 構造不正なstateではSha256Providerを1回も呼ばない
- `RunRuleSnapshot` schemaVersion `0.4.0`。完全Sprint1Configと完全技カタログをrun単位で1件だけ保持する
- `BattleRulesSnapshotRef` schemaVersion `0.1.0`。`relevantTechniqueIds`はTechniqueId昇順・重複排除
- `BattleActionSourceIdentity` schemaVersion `0.1.0`。default_strategy／scripted_actionsの両分岐とも7キー固定で、非該当キーは明示的`null`
- `BattleState` schemaVersion は正本現行 `0.6.0`（`S1-SPEC-0.1.17`）。S01-005実装時点の生成値は`0.5.0`だったが、`S1-SPEC-0.1.17` baseline clarificationで`0.6.0`／`sourceSnapshot`フィールドへ追随済み。作成直後はready、`beginBattle`成功でin_progress
- `StartBattleRuntimeTransition` schemaVersion `0.1.0`。World RNGとMatchIdGeneratorStateの進行後状態を1つに封入する
- 開始耐久は基準点整数で計算し、`startDurabilityPercentBasisPoints` として保持する（浮動小数を経由しない）
- `currentMental`はclampせず、`0..maxMental`外・非整数を開始前failureとする
- 参加資格は公式戦=active_competitor 16..41歳、模擬戦=trainee 8..15歳またはactive_competitor 16..41歳
- 負傷判定は`config.battle.injury.unableToContinueThreshold`を使用する（週次強制休養閾値とは別）
- `ageAtBattle`は既存の`computeCurrentAge(worldDate.year, birthYear)`から導出し、`person.currentAge`との一致を必須とする
- 成功時のみWorld RNGを`battleSeed`取得の1回だけ進める。失敗時は両runtime状態を入力と完全一致させる
- `reserveNextMatchId`／`createBattleState`／`beginBattle`／`startBattleTransaction`はpackage rootへ公開しない
- runtime transitionだけを適用する公開APIを設けない（実適用は12仕様の`commitRunBattlePlan`）
- `relevantTechniqueIds`は両参加者の**習得済み技**（`acquiredAbsoluteWeek !== null`）の和集合のみ。未習得既知技はsnapshotに残るがrefへは入らない
- `default_strategy`は`RunRuleSnapshot.defaultBattleStrategyVersion`と`sprint1ConfigHash`へ拘束する
- `createRunRuleSnapshot`は`SimulationIdentity`全文とfresh `MatchIdGeneratorState`へ拘束する
- `StartBattleRuntimeTransition`はexpected hashに加え、generator／World RNGの**厳密1ステップ**次状態を照合する
- 標準`BattleParticipantSource`は`{ person, temporaryCondition }`のみ。profile／injuryPronenessのcaller注入は拒否し、neutral 50へ固定する
- `sourceSnapshotHash`は戦闘開始`sourceSnapshot`（11 §12）から再計算照合する。正本`S1-SPEC-0.1.17` baseline clarificationで`sourceSnapshot`フィールド保持と常時検証へ追随済み。S01-006 fix5でmid-battle常時hash検証とDetailedLog replay validatorも実装済み。BattleResultはS01-007でimplemented / accepted（`a39e476`）。World commit配線はS01-008でproduction実装済み（accepted）。現行Sprint1仕様版identityは`S1-SPEC-0.1.20`
- `startBattleTransaction(input: unknown)`はexact 3 keysをdescriptor-safeにsnapshotする
- package rootからraw hash input型・低水準compute APIを除外する
- ターン解決、BattleResult、WorldEngine登録は対象外（S01-006以降）
